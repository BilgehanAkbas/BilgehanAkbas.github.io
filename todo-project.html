1. Sınıf Projesi - OOP Dersi Web Uygulaması

GitHub'da İncele

Bu sistem, sınıf arkadaşlarımla birlikte Nesne Yönelimli Programlama (OOP) yeteneklerimizi pratik bir ürüne dönüştürmek amacıyla geliştirdiğimiz bir Java web uygulamasıdır. Kullanıcıların görevlerini ve notlarını yönetebildiği, sohbet edebildiği güvenli bir altyapı üzerine kurulmuştur.

Temel Özellikler

  • Kullanıcı Yönetimi: Kayıt, giriş ve dinamik profil ayarları.
  • Görev Sistemi: Notları ve görevleri oluşturma, düzenleme, silme ve saklama işlemleri.
  • İletişim: Ayrı not ve görev sekmeleri barındıran bireysel ve grup sohbetleri.
  • Modern Arayüz: Bootstrap 5 ve JavaScript kullanılarak hazırlanan gradient tasarımlı duyarlı UI.
  • Gelişmiş Güvenlik: Tüm veriler BCrypt ile şifrelenir, Spring Security kullanılarak XSS/CSRF koruması ve form doğrulama işlemleri sağlanır.

Teknolojiler & Mimari

Java Spring Boot MySQL Spring Security & BCrypt
