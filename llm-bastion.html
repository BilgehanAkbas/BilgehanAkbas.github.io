LLMBastion

Türkçe, İngilizce ve karma dil girdilerinde prompt injection tespiti, hassas çıktı koruması ve güvenlik gözlemlenebilirliği sağlayan self-hosted, API-first LLM güvenlik gateway'i.

Ne çözüyor?

LLM kullanan bir uygulama ile model sağlayıcısı arasına güvenlik katmanı olarak yerleşir. İstek model sağlayıcısına gitmeden önce RuleGuard ve SemanticGuard v2 tarafından incelenir; izin verilen model yanıtı kullanıcıya dönmeden önce DataGuard v2 tarafından hassas veri açısından taranır.

Güvenlik hattı

  • RuleGuard: açık talimat geçersiz kılma, jailbreak, sistem promptu çıkarma ve güvenlik atlatma denemelerini deterministik kurallarla yakalar.
  • SemanticGuard v2: TF-IDF + Logistic Regression ile çok dilli prompt-injection olasılığı üretir.
  • RiskEngine: test edilmiş eşiklere göre block/allow kararı verir.
  • DataGuard v2: e-posta, Türk telefon numarası, JWT, özel anahtar blokları, doğrulanmış IBAN ve Luhn-geçerli kart numaraları gibi hassas çıktıları redakte eder.

Ölçüm ve mimari

SemanticGuard v2 için 1.200 satırlık dengeli sentetik veri seti üzerinde grup-duyarlı ayrım kullanıldı. Held-out değerlendirmede Precision 0.935, Recall 0.956 ve F1 0.945 elde edildi. Bu değerler proje içi kontrollü test sonucudur; üretim garantisi değildir.

Gateway ayrıca rate limiting, provider abstraction, audit/telemetry, dashboard, PostgreSQL/Redis destekli Docker Compose yapısı ve GitHub Actions test hattı içerir.

Benim odağım

Projede yalnızca bir LLM API sarmalayıcısı yapmak yerine, güvenlik kararının neden verildiğini izlenebilir hale getirmeye; yanlış pozitif/negatif dengesini ölçmeye; ham prompt ve model yanıtlarını gereksiz yere saklamadan audit üretmeye odaklandım.
